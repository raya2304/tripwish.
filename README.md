# TripWish — Travel Bucket List

**TripWish** is a responsive travel bucket list website designed to help users collect dream destinations, organize future trips, and keep track of places they have visited.

## About the Project

Everyone has places they dream of visiting. TripWish makes it easy to keep those travel dreams organized in one beautiful digital space.

Users can discover travel inspiration, add destinations to their personal bucket list, write notes about places they want to explore, and mark destinations as visited when their adventures are complete.

## Features

- **Destination Management:** Add and delete travel destinations.
- **Search Functionality:** Find destinations by name or country.
- **Status Filters:** View all destinations, planned trips, or visited places.
- **Travel Tracking:** Mark destinations as visited or planned.
- **Personal Notes:** Save reasons for wanting to visit a place.
- **Custom Photos:** Add image URLs for destinations.
- **Travel Statistics:** View destination counts and visited places.
- **Local Storage:** Keep saved destinations available after refreshing the browser.
- **Responsive Design:** Enjoy the website on desktop, tablet, and mobile screens.

## Technologies Used

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding destinations to your travel bucket list.

An internet connection is required for the external CSS framework, fonts, and online images.

## How to Use

1. Browse the suggested destinations for travel inspiration.
2. Click **Add destination** to add a place to your list.
3. Enter the destination name and country.
4. Optionally add a photo URL and personal note.
5. Choose whether the destination is planned or already visited.
6. Use the search bar and filters to organize your list.
7. Mark places as visited or remove destinations when needed.
